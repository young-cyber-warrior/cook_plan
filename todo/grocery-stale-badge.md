# TODO: бейдж «список устарел» (grocery)

Реализовать, когда рецепты переедут из моков в общий стейт/API (сейчас grocery читает `MOCK_RECIPES`, правки рецептов не видны — сравнивать не с чем).

## Логика

1. При генерации список уже сохраняет `sourceHash` (`GroceryList.sourceHash`, считается в `buildSourceHash` — `src/features/grocery/lib/build-list.ts`). Отпечаток источника:
   - каждый заполненный мил выбранных недель: `recipeId:servings`;
   - ингредиенты задействованных рецептов: `recipeId/normalize(name):amount+unit`.
2. На экране Продуктов пересчитывать хеш от **текущих** weeks + recipes:
   `buildSourceHash(weeks, list.weekIds, recipes)`.
3. `currentHash !== list.sourceHash` → список устарел. Ловит всё: добавили/убрали рецепт в миле, сменили порции, переименовали ингредиент, поменяли количество/единицу, удалили рецепт.

## UI

- Бейдж «список устарел» в строке сводки над списком (см. пин 3 в мокапе).
- Тап по бейджу = тот же флоу, что кнопка «Обновить» в навбаре (confirm при ручных правках).
