# TODO: автокомплит имён ингредиентов (рецепты)

Цель — чтобы один и тот же продукт в разных рецептах назывался одинаково: merge в списке продуктов идёт по ключу `normalize(name)|unit` (`itemKey` — `src/features/grocery/lib/build-list.ts`). «Помидор» и «Помидоры» — разные позиции, автокомплит сводит имена в источнике.

## Логика

1. Собрать словарь имён: все `ingredient.name` из всех рецептов, уникализировать по `normalize(name)`, отсортировать по частоте использования.
2. В поле имени ингредиента (форма рецепта — `ingredient-row.tsx` / `use-recipe-editor.ts`) при вводе от 2 символов показывать подсказки: сначала `startsWith`, затем `includes`.
3. Тап по подсказке подставляет каноничное имя (и можно подставлять привычную единицу этого продукта).
4. Совпадений нет → обычный ввод, имя попадёт в словарь после сохранения.

## UI

- Выпадающий список под инпутом внутри шита рецепта, 3–5 подсказок максимум.
- Подсказка показывает имя + единицу (`Помидор · г`).
