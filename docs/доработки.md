# Доработки

## Логирование

Сейчас логов нет — только россыпь `console.error` в `catch`/`onError` и молчаливый `write()` ([src/stores/write.ts](../src/stores/write.ts)), который глотает ошибку в консоль без контекста.

Что не видно:

- какое действие выполнялось (`generate`, `addRecipe`, `resizeWeek` — все пишут одинаковый `local write failed`);
- дошёл ли write до сервера или лёг в очередь PowerSync;
- почему прервался `init` (abort при unmount vs реальный сбой);
- ошибки `powersync.watch` — уходят в консоль, пользователю ничего.

Нужно:

- единый логгер с уровнями (`debug`/`info`/`warn`/`error`) и тегом источника;
- `write(promise, 'grocery.generate')` — контекст в каждый вызов;
- отключение `debug` в проде;
- решить, что показывать пользователю (см. вопрос про обработку ошибок в сторах).
